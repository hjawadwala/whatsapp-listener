🔄 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User Flow:
1. Open http://localhost:3000
2. Click "Connect New Session"
3. See token displayed
4. Click "Copy Token"
5. Token in clipboard
6. Use token in API call
7. Message sent from session's number
8. Audit logged automatically


API Knows Number:
1. API request includes Authorization header with token
2. Backend extracts token
3. Looks up token in sessionTokens Map
4. Finds sessionId
5. Looks up sessionId in sessions Map
6. Gets phoneNumber
7. Sends message from that number
8. No need to specify number in request
